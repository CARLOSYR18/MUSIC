# Spotify Web & Mobile Player (React + Vite + TypeScript)

Reproductor de música con diseño profesional idéntico a Spotify (Desktop y Mobile), streaming continuo y búsquedas ilimitadas.

## Características

- 🎵 **Diseño Spotify Desktop & Mobile**: Interfaz fiel y responsiva con barra de navegación inferior móvil, mini reproductor flotante y carruseles táctiles.
- ⚡ **Búsquedas Ilimitadas**: Integración directa por proxy nativo sin límites de cuota diaria de API.
- 👤 **Perfiles de Artistas y Álbumes**: Banners, canciones populares, discografía completa y carátulas en alta resolución.
- 📱 **Vistas Móviles Nativas**:
  - Pestañas: Inicio, Buscar, Tu biblioteca, Crear.
  - Accesos rápidos en 2 columnas compactas.
  - Sección «Escuchar ahora» y carrusel deslizable «Sigue reproduciendo».
  - Mini reproductor flotante con barra de progreso interactiva.
- ❤️ **Biblioteca y Me gusta**: Guardado local persistente de favoritos e historial real de reproducción.

## Instalación y ejecución

```bash
npm install
npm run dev
```

Abre `http://localhost:5173` en tu navegador.
